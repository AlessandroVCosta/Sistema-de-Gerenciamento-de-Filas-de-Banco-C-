Sistema de Gerenciamento de Filas de Banco


Este projeto implementa um sistema de gerenciamento de filas para um banco
Desenvolvido como Trabalho de Final de Semestre na disciplina de Estruturas de Dados II. 
O objetivo é simular o processo de chegada de clientes, organização em fila e atendimento de acordo com critérios de prioridade, usando estruturas de dados adequadas (filas, filas de prioridade, listas ligadas, etc.).

- Funcionalidades
  
	•	Entrada de Clientes: Adiciona novos clientes à fila gerando uma senha,com as informações de tipo de atendimento(prioritário ou não) e registra o horário de chegada.
	•	Atendimento Simulado: Remove clientes da fila para simular o processo de atendimento, registrando o tempo médio de espera.
	•	Relatórios Básicos: Gera estatísticas simples sobre número de atendimentos por tipo de prioridade e tempo médio de serviço.


- Tecnologias Utilizadas
  
	•	Linguagem: C 
	•	Estruturas de Dados: Filas Simples, Filas de Prioridade, Listas Ligadas
	•	Ambiente de Desenvolvimento: DevC++
